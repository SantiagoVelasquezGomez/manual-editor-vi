🐧 Manual de Aprendizaje del Editor VI
📖 Descripción

Este repositorio documenta mi proceso de aprendizaje del editor de texto vi en sistemas Linux.

El proyecto funciona como un manual práctico y como una bitácora personal donde registro los comandos aprendidos, las dificultades encontradas, los errores cometidos y las soluciones aplicadas durante el proceso de aprendizaje.

También se utiliza Git y GitHub para aplicar un flujo de trabajo similar al utilizado en proyectos de desarrollo de software.

🎯 Objetivos
Aprender a utilizar el editor vi.
Comprender los diferentes modos de trabajo.
Practicar comandos de navegación.
Aprender comandos de edición.
Guardar y salir correctamente de un archivo.
Buscar texto dentro de documentos.
Documentar problemas reales encontrados durante el aprendizaje.
Utilizar Git y GitHub mediante commits, branches y Pull Requests.
Publicar el manual utilizando GitHub Pages.
